# 固件烧录教程（CH340 + FlyMcu）

本项目使用 **CH340 串口 ISP 下载**，不需要 ST-Link，也不需要安装编译器即可烧录。

## 一、准备工作

- 硬件：桌宠主板（STM32F103C8T6）+ CH340 USB 转 TTL 模块 + USB 数据线
- 软件：**FlyMcu**（单片机在线编程网免费软件，绿色单文件）
- 固件：[`firmware/release/`](../firmware/) 目录下的 `.hex` 文件

## 二、接线

CH340 模块与桌宠烧录口连接（**TX/RX 交叉对接**）：

| CH340 模块 | 桌宠板 |
|---|---|
| TX | RX |
| RX | TX |
| GND | GND |
| 5V / 3.3V | 3.3V（按板载供电需求） |

> ⚠️ 千万不要给 STM32 供 5V——它是 3.3V 电平芯片。

## 三、FlyMcu 配置

1. 打开 FlyMcu，点击「搜索串口」，选择 CH340 对应的 COM 口
2. 波特率选择 **115200**（F103 无需降速，卡顿再试 96000/57600）
3. 点击「选择文件」，载入 `.hex` 固件
4. 左下角关键选项勾选：**「DTR 低电平复位，RTS 高电平进 BootLoader」**（一键下载电路必备）
5. **不要勾**「使用 RamIsp」，**不要勾**「编程到 FLASH 时写选项字节」

## 四、开始烧录

- **板载一键下载电路**：直接点「开始编程」，等待进度条走完，提示成功即可
- **无一键下载电路**：
  1. 烧录前将 **BOOT0 接 3.3V**、BOOT1 接 GND
  2. 按一下复位键，让芯片进入 BootLoader
  3. 点「开始编程」
  4. 烧录完成后，**务必把 BOOT0 拔回 GND**，再按一次复位，程序才会运行

## 五、常见问题

| 现象 | 排查方向 |
|---|---|
| 搜索不到 COM 口 | 检查 CH340 驱动是否安装（设备管理器看端口） |
| 一直「连接中…」后失败 | 检查 TX/RX 是否交叉、GND 是否共地；换根 USB 线 |
| 烧录成功但屏幕不亮 | BOOT0 没拔回 GND；检查 OLED 排线 |
| 提示芯片超时 | 板子供电不足，换 USB 口或外部供电 |
